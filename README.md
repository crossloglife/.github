# crossloglife/.github

組織共通の Issue / PR テンプレートの置き場所。

- `.github/ISSUE_TEMPLATE/` と `.github/PULL_REQUEST_TEMPLATE.md` が、自前のテンプレートを持たないリポジトリの既定になる
- リポジトリ側に `.github/ISSUE_TEMPLATE/` が 1 ファイルでもあると、Issue テンプレートはこちらが丸ごと使われなくなる（PR テンプレートも同じくリポジトリ側が優先）
- 既定として読まれる条件として、このリポジトリは公開のままにする。テンプレート・PR・コミットメッセージに、機能名・顧客の情報・非公開のリポジトリの名前や中身・社内の運用を書かない
